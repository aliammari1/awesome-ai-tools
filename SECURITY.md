# Reporting a Bad or Unsafe Tool

This repository is a curated markdown list of links to third-party AI tools. It ships
no software of its own, so there is nothing here to exploit. What can go wrong is a
**listed link pointing somewhere it should not** — a tool that has been taken over,
turned malicious, started serving malware, or had its domain expire and re-registered
by someone else.

If you spot an entry like that, please help us pull it quickly.

## How to report

Email **contact@aliammari.com** with `[awesome-ai-tools]` in the subject and include:

- the entry name and the URL as it appears in the list,
- what is wrong (dead domain, redirect to malware, phishing, hijacked project, etc.),
- and anything that backs it up (a screenshot, a scanner result, an official notice).

Please report a suspicious link by email rather than opening a public issue, so the
entry can be removed before it is widely shared. Confirmed problem links are taken out
of the list as soon as they are verified.

## A note for users

Every entry here links to an external product run by someone else. Inclusion in this
list is not an endorsement or a security guarantee. Review a tool's own privacy policy
and terms before trusting it with sensitive data.
